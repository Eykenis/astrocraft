# Astrocraft 项目介绍网页

这是由 `Astrocraft.pptx` 导出的可翻页网页幻灯片，共 29 页。页面保留了原始幻灯片的版式、文字、公式和图表，并在原位置播放 GIF/视频演示。

## 使用

直接双击 `index.html` 即可打开。也可以把整个文件夹内容上传到 GitHub Pages、静态网站托管或个人服务器；保持 `index.html`、`assets/` 和本说明文件的相对位置不变。

## 操作

- `←` / `→`、PageUp / PageDown：翻页
- `Home` / `End`：跳到第一页 / 最后一页
- `G`：打开目录
- `F`：进入或退出全屏
- 移动端可左右滑动翻页

循环演示默认静音自动播放；视频演示保留原音频，需要点击视频控件播放。网页使用相对路径，可从 `file://` 直接打开，也适合部署到 GitHub Pages 子路径。

原 PowerPoint 中的页面切换动画没有转换为网页动画；页面内容和嵌入的动态演示已保留。
